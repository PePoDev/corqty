# Code of conduct

Corqty welcomes participants with different backgrounds and experience levels.
Treat people with respect, focus criticism on the work, and make technical
disagreement constructive. Explain decisions, acknowledge mistakes, and give
others room to learn.

Harassment, threats, discriminatory abuse, unwanted sexual attention, deliberate
misrepresentation, and publishing another person's private information are not
acceptable. Do not use project spaces for spam or repeated personal attacks.
These expectations apply to issues, pull requests, reviews, discussions, and
other spaces representing the project.

Maintainers may edit or remove inappropriate content, request a change in
behavior, limit participation, or block participants where necessary. Responses
should consider context, impact, and repeated behavior. Maintainers are expected
to follow the same standards and avoid handling complaints in which they have a
personal conflict when another maintainer is available.

For a concern, contact a maintainer through an available private channel. If no
private project contact is published, request one without posting sensitive
details, or use the hosting platform's reporting tools. Keep reports factual and
share only the information needed to assess the concern. The project does not
promise confidentiality beyond the reporting channel's controls or a fixed
response time.
